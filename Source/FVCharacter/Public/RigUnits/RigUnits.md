## Overview

These RigUnits extend Unreal's Control Rig system with procedural animation capabilities. They run on the animation thread within the RigVM, providing high-performance skeletal modification.

### When to Use RigUnits vs Other Systems

| System | Use Case |
|--------|----------|
| **RigUnits** | Math-heavy procedural modification, IK target calculation, phase-driven animation |
| **AnimDynamics** | Physics-based secondary motion on bone chains (hair, cloth, capes) |
| **C++ Components** | Game thread traces, world queries, collision detection |

## FFVRigUnit_ArmSwingPhase

Phase-driven arm swing modifier with spring-damper physics simulation.

### Purpose

Procedurally controls arm swing during locomotion based on a walk cycle phase value. Creates natural arm motion ranging from relaxed/sloppy to tense/stiff.

### Algorithm

#### 1. Phase-to-Swing Conversion

The walk cycle phase (-1 to 1) is converted to a swing factor using a sine wave for natural pendulum motion:

```cpp
// Contralateral coordination: left arm opposite to left leg
float EffectivePhase = bIsLeftArm ? -Phase : Phase;

// Sine wave creates pendulum motion
// Phase [-1, 1] ? SwingFactor [-1, 1]
SwingFactor = sin(EffectivePhase * ? / 2)
```

**Reference**: Basic pendulum motion follows sinusoidal displacement. See [Simple Harmonic Motion](https://en.wikipedia.org/wiki/Simple_harmonic_motion).

#### 2. Spring-Damper Physics

The arm doesn't instantly reach its target - it follows with lag/overshoot based on stiffness. This uses a classic spring-damper (mass-spring-damper) system:

```
F_spring = -k * (x - x_target)     // Spring force toward target
F_damping = -c * v                  // Damping force opposing velocity
F_total = F_spring + F_damping
a = F_total / m                     // Acceleration (m=1 simplified)

// Semi-implicit Euler integration
v += a * dt
x += v * dt
```

**Parameters from Stiffness**:

| Stiffness | Spring K | Damping | Behavior |
|-----------|----------|---------|----------|
| 0.0 (Relaxed) | 8 | 0.3 (underdamped) | Bouncy, overshoot, floppy |
| 0.5 (Natural) | ~30 | ~0.6 | Balanced follow-through |
| 1.0 (Tense) | 80 | 1.2 (overdamped) | Rigid, no overshoot |

**Reference**: [Mass-Spring-Damper System](https://en.wikipedia.org/wiki/Mass-spring-damper_model), [Critically Damped Systems](https://en.wikipedia.org/wiki/Damping#Critical_damping).

#### 3. Swing Offset Calculation

Three components of arm swing:

```cpp
// Longitudinal (forward/back) - primary swing
ForwardOffset = ForwardAxis * 20cm * SwingFactor * SwingAmount

// Lateral (outward at extremes)
LateralOffset = RightAxis * 4cm * |SwingFactor| * SwingAmount

// Vertical (arm rises at swing peaks)
VerticalOffset = UpAxis * 6cm * |SwingFactor| * SwingAmount
```

#### 4. Randomness (Organic Variation)

Multi-octave sine-based noise prevents mechanical repetition:

```cpp
Noise = sin(t * 2.13) * 0.5 
      + sin(t * 3.51) * 0.3 
      + sin(t * 5.17) * 0.2

// Applied to:
// - Amplitude: ±Randomness variation
// - Timing: ±Randomness * 0.1 phase shift
// - Stiffness: ±Randomness * 0.15 variation
```

**Reference**: [Perlin Noise](https://en.wikipedia.org/wiki/Perlin_noise) (simplified sine approximation).

### Inputs

| Input | Type | Description |
|-------|------|-------------|
| `WristReference` | FRigElementKey | Buffer control storing animated wrist pose |
| `ElbowPoleReference` | FRigElementKey | Buffer control for elbow pole vector |
| `ShoulderReference` | FRigElementKey | Shoulder for coordinate frame |
| `Phase` | float [-1, 1] | Walk cycle phase from curve |
| `SwingAmount` | float [0, 3] | 0=none, 1=normal, >1=exaggerated |
| `Stiffness` | float [0, 1] | 0=sloppy, 0.5=natural, 1=tense |
| `Randomness` | float [0, 0.5] | Organic variation amount |
| `bIsLeftArm` | bool | Auto-inverts phase for coordination |
| `bDrawDebug` | bool | Visualize targets |
| `BlendWeight` | float [0, 1] | Overall effect weight |

### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `WristTargetPosition` | FVector | World-space IK target for wrist |
| `WristTargetRotation` | FQuat | Wrist rotation |
| `ElbowPoleTarget` | FVector | Pole vector for TwoBoneIK |
| `SwingFactor` | float [-1, 1] | For driving other effects (finger curl, etc.) |

## FFVRigUnit_SoftBodySim

Spring-mass physics for body soft tissue (stomach, breast, buttocks, muscle).

**Note**: For hair and cloth, use AnimDynamics instead - it's better suited for bone chains with collision.

### Presets

| Preset | Stiffness | Damping | Mass | Use Case |
|--------|-----------|---------|------|----------|
| Stomach | 12 | 0.45 | 1.5 | Fatty tissue, slow wobble |
| Breast | 18 | 0.35 | 0.8 | Responsive, medium bounce |
| Buttocks | 20 | 0.5 | 1.2 | Firm, subtle movement |
| Muscle | 30 | 0.6 | 1.0 | Stiff, quick settle |

## FFVRigUnit_ProximityBlend

Distance-based blend weight calculation with multiple falloff curves.

### Falloff Types

| Type | Formula | Use Case |
|------|---------|----------|
| Linear | `1 - t` | Simple distance fade |
| Smooth | `3t² - 2t³` (smoothstep) | Natural transitions |
| Squared | `t²` | Quick initial fade |
| InverseSquared | `?t` | Slow fade, quick end |
| Exponential | `1 - e^(-3t)` | Realistic light falloff |

## FFVRigUnit_LegStepWidth

Phase-driven leg step width modifier with overlap prevention.

### Purpose

Controls lateral foot placement from catwalk (narrow) to wide stance. Prevents feet from crossing/overlapping during narrow stances.

### Step Width Values

```
CATWALK (StepWidth = -1)       NORMAL (StepWidth = 0)        WIDE (StepWidth = +1)
        ?                            ?    ?                         ?         ?
        ?                            ?    ?                         ?         ?
       ??? ? feet cross             ????????                       ?????????????
        ?   midline                  ?    ?                         ?         ?
        ?                            L    R                         L         R
```

### Plant Weight Integration

Uses animation curves to know which foot is grounded:
- **Planted foot (PlantWeight = 1)**: Minimal movement, stable base
- **Swinging foot (PlantWeight = 0)**: Full lateral offset applied

### Inputs

| Input | Type | Description |
|-------|------|-------------|
| `LeftFootIKControl` | FRigElementKey | Left foot IK control |
| `RightFootIKControl` | FRigElementKey | Right foot IK control |
| `PelvisReference` | FRigElementKey | Pelvis for lateral direction |
| `Phase` | float [-1, 1] | Walk cycle phase |
| `LeftPlantWeight` | float [0, 1] | From left_leg_plant curve |
| `RightPlantWeight` | float [0, 1] | From right_leg_plant curve |
| `StepWidth` | float [-1, 1] | -1=catwalk, 0=normal, +1=wide |
| `MinSeparation` | float | Minimum foot separation (cm) |
| `Stiffness` | float [0, 1] | Movement stiffness |

### Outputs

| Output | Type | Description |
|--------|------|-------------|
| `LeftFootTargetPosition` | FVector | Modified left foot position |
| `RightFootTargetPosition` | FVector | Modified right foot position |
| `CurrentSeparation` | float | Actual foot separation |
| `bOverlapCorrected` | bool | Was overlap prevention triggered |

## UFVLocomotionStyleData

Data asset for storing locomotion style parameters.

### Purpose

Centralizes all procedural animation parameters in a single data asset. Create multiple instances in the editor for different styles (Masculine, Feminine, Tired, Drunk, etc.).

### Usage

1. Right-click in Content Browser ? Miscellaneous ? Data Asset
2. Select `FVLocomotionStyleData` as the class
3. Name it (e.g., `DA_LocomotionStyle_Feminine`)
4. Adjust parameters
5. Reference in character/animation blueprint

### Parameters

| Category | Parameter | Range | Description |
|----------|-----------|-------|-------------|
| **Hip** | HipSwingAmount | 0-2.5 | Hip swing amplitude |
| | HipLateralSwing | 0-2 | Side-to-side sway |
| | HipVerticalBob | 0-2 | Up-down bounce |
| | HipRotation | 0-2 | Twist amount |
| **Spine** | SpineBendAmount | 0-2 | Overall flexibility |
| | SpineCompensation | 0-1 | Counter-rotation |
| | SpineLean | -1 to 1 | Forward/back lean |
| **Arms** | ArmSwingAmount | 0-3 | Swing amplitude |
| | ArmStiffness | 0-1 | Muscle tension |
| | ArmAsymmetry | -1 to 1 | Left/right difference |
| **Legs** | StepWidth | -1 to 1 | Narrow to wide stance |
| | MinStepSeparation | 0-30 | Overlap prevention |
| | LegStiffness | 0-1 | Movement stiffness |
| **Global** | Randomness | 0-0.5 | Organic variation |
| | EnergyLevel | 0.3-2 | Overall intensity |
